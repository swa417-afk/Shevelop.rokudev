# Contributing to Shevelop Roku Channel

Thank you for your interest in contributing to Shevelop.

## Contribution Guidelines

### Code Standards
- Follow Roku SDK and SceneGraph best practices
- Keep components modular and readable
- Avoid hardcoding URLs or credentials

### Commit Messages
Use clear, descriptive messages:
- feat: add episode grid pagination
- fix: playback resume bug
- chore: cleanup unused components

### Pull Requests
Include:
- Description of changes
- Screenshots or video (if UI-related)
- Testing notes

### Content Policy
Do not add:
- Proprietary media
- Guest content
- Branding assets
- API keys or secrets

All contributions must comply with the MIT License.
