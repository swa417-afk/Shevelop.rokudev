## Color Palette Reference

- **Neon Magenta:** #FF1FB6
- **Electric Lime:** #9BFF00
- **Hot Pink:** #FF1FB6
- **Ink Black:** #000000

## Technical Requirements

- Resolution: 1920×1080 pixels (16:9 aspect ratio)
- Format: PNG
- File size: Keep under 2MB for optimal Roku performance
- Color depth: 24-bit RGB
- No transparency needed (Roku uses RGB, not RGBA)
